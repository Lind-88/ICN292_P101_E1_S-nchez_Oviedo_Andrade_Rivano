Este repositorio contiene la propuesta integral de un sistema de informacion para la gestion diseñado para la optimizacion del trabajo con datos de nuestra pyme.

La pyme a estudiar sera "almacen la maestra" ubicado en Av. Fontt 1244 en la comuna de Colina, pyme dedicada a la venta de mercaderia y abarrotes clasicos de consumo diario.

La pyme presenta importantes limitaciones actualmente, entre ellas:
1)Gestion manual en excel 
2)Toma de decisiones sin analisis basado en datos
3)Control de inventario e insumos impreciso

En conjunto el problema central es la falta de un sistema de informacion centralizado que permita analizar datos y factores relevantes para la gestion del almacen.

Nuestra solucion propuesta busca crear un SIG que sea 

1) Amigable y simple de entender, mediante formularios tipo pop up para registrar ventar diarias, egresos y compras.
2) Almacenamiento centralizado en una base de datos MySQL
3) Visualizacion de KPIs y rendimiento financiero

Ademas de esto presentamos automatizaciones como recordatorios automaticos o sugerencias de compras de elementos.
