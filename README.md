(1) Este repositorio contiene la propuesta integral de un Sistema De Informacion para la Gestion diseñado para la optimizacion del trabajo con datos de nuestra pyme.

La pyme a estudiar sera "almacen la maestra" ubicado en Av. Fontt 1244 en la comuna de Colina, pyme dedicada a la venta de mercaderia y abarrotes clasicos de consumo diario.

La pyme presenta importantes limitaciones actualmente, entre ellas:

1) Gestion manual en excel 
2) Toma de decisiones sin analisis basado en datos
3) Control de inventario e insumos impreciso

En conjunto el problema central es la falta de un sistema de informacion centralizado que permita analizar datos y factores relevantes para la gestion del almacen.

Nuestra solucion propuesta busca crear un SIG que sea 

1) Amigable y simple de entender, mediante formularios tipo pop up para registrar ventar diarias, egresos y compras.
2) Almacenamiento centralizado en una base de datos MySQL
3) Visualizacion de KPIs y rendimiento financiero

Ademas de esto presentamos automatizaciones como recordatorios automaticos o sugerencias de compras de elementos.

(2) Este repositorio cuenta con distintas carpetas dentro de las cuales se encuentran:

1) Informe: Aca se podra encontrar un detallado informe sobre la pyme, su situacion actual y problemas, las soluciones propuestas, ademas de diagramas en BPMN para la expliacion de estos mismos.
2) Assets: Aca se podra encontrar las imagenes .PNG y los .bpm de los procesos de la empresa AS-IS y TO-BE
3) Docs: Una descripcion escrita de lo realizado.

(3) Toda la informacion obtenida en en esta 1era parte de la entrega del proyecto genera las bases para la 2da entrega:

-Base de Datos: El diseño del modelo ER se concreta en la creacion de la base de datos en SQL
-Interfaz de Usuario: La propuesta de formularios tipo "pop up" para registrar ventas, compras y egresos se materializa en una apliacion
-Toma de decisiones: Loa datos almacenados se utilizan par hacer un seguimiento con KPIs 
-Automatizacion: Se genera la automatizacion mediante n8n de alguno de los procesos tomados en los diagramas bpmn.
